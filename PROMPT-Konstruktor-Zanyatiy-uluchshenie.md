## ЖАЛОБЫ И РЕШЕНИЯ ВЛАДЕЛЬЦА (обязательны к исполнению)
1. Задания рабочего листа скучные и «схематичные» → должны быть **как в печатных пособиях** («Обведи», «Раскрась», «Соедини линией», «Впиши цифру», «Зачеркни лишнее»), интересные, с понятной инструкцией ребёнку и крупными картинками.
2. Интерфейс тяжёлый → **проще и понятнее**, минимум шагов.
3. Не только логопедия: добавить направления **Логика и внимание, Графомоторика, Грамота и буквы, Творчество** (к имеющимся Речь, Математика/ФЭМП, Окружающий мир, Смешанное).
4. Математика «нормальная»: **задачи с сюжетом, примеры и состав числа (домики), геометрия и измерение, логические задачи**; знаки `>`, `<`, `=` и диапазон чисел строго по возрасту.
5. Вид листа — **все три режима**, переключатель: «Печатное пособие (ч/б контуры, 2–3 задания на А4)» · «Цветной (как сейчас, плотнее)» · «ИИ-иллюстрации (онлайн, с кэшем и офлайн-фолбэком на встроенные рисунки)».
6. ИИ: **работа без своего сервера**, автономно; редактор провайдеров/ключей прямо в приложении (добавить, изменить, удалить, проверить, выбрать по умолчанию).

## ЗАДАЧИ

### A. Задания рабочего листа (ядро ценности)
- Каждое задание = объект `{id, area, ages:[4,5,6], action, instruction(ребёнку, ≤12 слов, повелит. наклонение), build(theme, age, rng) → {svg|html, answer, hintForAdult}, printable:true}`; детерминированный `rng(seed)` → кнопка «Другие слова» меняет seed.
- Все задания строятся **только из слов выбранной темы** (сохранить принцип v1.2); картинка = то же слово, что в тексте.
- Добавить минимум **35 новых** типов (итого ≥ 65), каждый с реальным действием ребёнка:

| Направление | Новые задания (минимум) |
|---|---|
| Математика 4–5 (до 5) | Обведи столько, сколько цифра · Соедини группу с цифрой · Где больше? Поставь точку · Раскрась 3-й по счёту · Длинный/короткий · Обведи круги/квадраты/треугольники |
| Математика 5–6 (до 8–10) | Сюжетная задача с картинкой и окошком ответа · Домик состава числа · Поставь знак `>` `<` `=` (картинки → цифры) · Соседи числа · Числовой ряд с пропуском · Измерь мерками (клеточками) · Продолжи узор из фигур |
| Математика 6–7 (до 10/20) | Примеры `a ± b` в пределах 10 с картинкой-подсказкой · Задачи на сложение/вычитание (условие-вопрос-решение-ответ) · Сравни числа знаками · Математический диктант по клеточкам · Логическая задача («Кто выше?») · Часы: целый час · Дни недели/время года по порядку |
| Логика и внимание | Найди отличия (2 картинки, 3–7 отличий по возрасту) · Чья тень? · Найди такую же · Что лишнее (по признаку) · Судоку 4×4 с картинками · Что сначала, что потом (серия из 3–4) · Лабиринт (уровни 1–3) |
| Графомоторика | Обведи по точкам (контур предмета темы) · Штриховка (горизонт./вертик./наклон) · Дорожки (прямые, волны, зигзаг, петли) · Дорисуй вторую половину (симметрия) · Графический диктант |
| Грамота и буквы | Найди и обведи букву · Первый/последний звук (схема звука цветом) · Звуковая схема слова (кружки красный/синий/зелёный) · Прочитай слог и соедини с картинкой · Сколько слогов — столько хлопков (впиши цифру) · Буква спряталась |
| Творчество | Раскрась по цифрам/по образцу · Дорисуй предмет · Вырежи и наклей (линии реза) · Составь картинку из фигур |
| Речь (усилить существующие) | Назови и раскрась только тех, у кого звук [X] · Один—много с картинками-парами · Соедини маму и детёныша · Подбери признак (какой?) · Мнемотаблица с пустыми клетками для рассказа |

- Возрастная матрица (`ages.js`): диапазон чисел, кол-во предметов, кол-во заданий на лист (4–5: 3–4, 5–6: 4–6, 6–7: 5–8), размер шрифта инструкции, сложность лабиринта/отличий, разрешённые знаки и операции. Ни одно задание не генерирует число вне диапазона возраста — покрыть тестом.
- Каждая страница листа: шапка «Имя ___ Дата ___», нумерация, иконка действия (карандаш/ножницы/цветной карандаш), поля 15 мм, без обрезки на А4; печать ч/б без потери смысла (цвет — только дублирующий признак).
- Режим «С ответами» для взрослого: ответ + методическая подсказка под заданием (уже есть — сохранить для всех новых).

### B. Интерфейс (проще, быстрее)
- Главный экран = **3 действия**: «Быстрое занятие» (тема текущей недели + возраст из настроек → готово за 1 тап) · «Собрать вручную» · «Мои занятия».
- Мастер вместо длинной формы: **Тема → Группа → Задания → Готово**, прогресс-бар, «Назад»/«Далее» в доке, разумные значения по умолчанию на каждом шаге (технологии, длительность по СанПиН, речевое заключение — свернуть в «Дополнительно»).
- Выбор заданий — **карточки с превью-миниатюрой**, фильтр по направлению чипами, перетаскивание порядка, «Заменить» на карточке.
- Предпросмотр листа = реальные страницы А4 (масштаб под экран, свайп по страницам), правка текста инструкции тапом.
- Тема недели: автоподбор по календарю учебного года (сентябрь–май), поиск с подсветкой.
- Крупные тап-зоны ≥ 48 dp, шрифт ≥ 16 px, контраст WCAG AA, тёмная тема, системная кнопка «Назад» корректно ведёт по шагам, без потери введённого.
- Пустые/ошибочные состояния с понятным текстом и действием («Нет интернета — использованы встроенные рисунки»).
- Онбординг 3 экрана при первом запуске (учреждение, ФИО, должность, группа/возраст) → дальше не спрашивать.

### C. ИИ без сервера, с редактором провайдеров
- Экран «Нейросети»: список провайдеров (DeepSeek, GigaChat, Qwen, Pollinations, OpenRouter, Groq, Gemini, HuggingFace + **«Свой (OpenAI-совместимый)»**): поля `name, baseUrl, apiKey (маска, показать/скрыть), model, imageModel, enabled, priority`; кнопки «Проверить» (тестовый запрос, время ответа, текст ошибки), «По умолчанию», «Удалить»; **автопереключение** на следующий провайдер при ошибке/лимите/таймауте (таймаут 25 с).
- Импорт/экспорт конфигурации ИИ: JSON-файл и вставка из буфера; при импорте — валидация схемы и показ, что будет изменено.
- Ключи владельца: файл `app/assets/www/js/keys.local.js` (в `.gitignore`, **никогда не коммитить**), `build.sh` подхватывает его, если существует → личная сборка работает «из коробки»; без файла — сборка без ключей, ввод в настройках. Публичный APK в репозитории — только без ключей; личный APK — только в `dist-private/` (в `.gitignore`) и отправлять владельцу напрямую.
- Ключи хранить в `SharedPreferences` через `AndroidBridge` (а не только `localStorage`), чтобы переживали очистку WebView-кэша.
- ИИ — только усилитель: всё ядро (задания, конспект, техкарта, Word, печать) работает офлайн. ИИ-функции: «Придумать загадку/стих/сказку по теме», «Переписать инструкцию проще», «Сгенерировать иллюстрацию» (кэш в IndexedDB).
- Ответы ИИ проверять: длина, отсутствие латиницы/markdown в тексте для детей, слова темы присутствуют; иначе — повтор или фолбэк на шаблон.

### D. Документы
- Word (DOCX по ГОСТ): новые задания и SVG → PNG в документе, без разрывов внутри задания (`keepNext`/`cantSplit`), альбомная техкарта, книжный лист.
- Конспект/техкарта автоматически получают этапы под выбранные направления (графомоторная разминка, логическая игра, грамота) с теми же номерами заданий, что в листе.
- Цели/задачи и планируемые результаты — формулировки по ФОП ДО для каждого направления и возраста.
- Задание родителям — 3–5 игр по теме для дома с понятными инструкциями без терминов.
- Пакетная выгрузка: «Неделя» (тема × 2–3 занятия) одним DOCX/ZIP.

### E. Данные и надёжность
- Резервная копия: экспорт/импорт всего (настройки, история, свои темы, свои картинки, конфигурация ИИ без ключей по умолчанию, с ключами — по галочке) в один файл `.kzbackup` (JSON+base64).
- Свои темы и слова: редактор (слово, мн. число, ласкательная форма, детёныш, признаки, действия, картинка из галереи/ARASAAC) → сразу участвуют во всех заданиях.
- Миграции версий хранилища (`schemaVersion`), без потери данных при обновлении с 1.2.x/1.3.x.
- Производительность: ленивое подключение `data/themes_*.js` и SVG, генерация листа < 1 с на бюджетном телефоне, без утечек (снимать обработчики, освобождать `URL.createObjectURL`).
- Глобальный перехват ошибок JS → понятное сообщение + «Скопировать отчёт».
- Android: minSdk 23, targetSdk 34, сохранение в «Загрузки/Конструктор занятий» через MediaStore (Android 10+) и `WRITE_EXTERNAL_STORAGE` только для ≤ 28.

### F. Качество (обязательно перед выдачей APK)
- Расширить `tools/selftest.js`: для **каждой темы × каждого возраста × каждого задания** — генерация без исключений, все слова из темы, числа в диапазоне возраста, у каждого задания есть `instruction`, `answer`, корректный SVG; DOCX открывается (валидный ZIP/XML); ≥ 1 детерминированный снимок листа на направление.
- `node tools/selftest.js` → «замечаний: 0», `prepare_assets.js --check` чистый.
- Визуальная проверка: отрендерить по 1 листу каждого направления в PNG (Playwright/Chromium, A4) и самому просмотреть: нет наложений, обрезки, пустых картинок, мелкого текста.
- Поднять `VERSION_CODE` (+1) и `VERSION_NAME` (→ 1.4.0), обновить README (таблица направлений и заданий, раздел «Нейросети»), CHANGELOG.
