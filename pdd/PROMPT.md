# Промпт: сайт-тренажёр для быстрого заучивания билетов ПДД

Скопируйте блок ниже целиком в ИИ-агента (Claude Code, Cursor, Copilot и т. п.).

```text
РОЛЬ: Senior frontend-инженер и специалист по методикам обучения (cognitive science of learning).

ЦЕЛЬ: Статический сайт-тренажёр, который за минимальное время доводит человека — даже со слабой памятью — до уверенной сдачи теоретического экзамена ПДД РФ в ГИБДД. Результат должен работать «под ключ» с первой попытки: без плейсхолдеров, TODO и «допишите сами».

ДАННЫЕ
- Источник: https://github.com/etspring/pdd_russia (актуальные билеты ГИБДД, категории A_B и C_D, 40 билетов × 20 вопросов = 800 на категорию, картинки, знаки signs/signs.json, разметка markup/markup.json).
- Напиши скрипт сборки на Python (stdlib) tools/build_pdd_data.py <src> <out>:
  - data/<ab|cd>/q.json: {topics:[...], q:[{id,t,n,q,img,a:[...],c,tip,tp:[...]}]} — c = индекс единственного правильного ответа (проверять, что он ровно один; в билете ровно 20 вопросов, иначе ошибка сборки);
  - картинки не отдельными файлами, а чанками по билетам data/<cat>/img/NN.json = {hash: dataURI} (нужно ≤ 255 файлов на хостинге и ленивую загрузку);
  - data/signs.json и data/markup.json с картинками в dataURI;
  - нормализовать пробелы, не выходить за пределы исходной папки при чтении картинок.

СТЕК
- Vanilla HTML/CSS/JS, без сборки и фреймворков, один app.js + app.css. Работает с любого статического хостинга и в песочнице (fetch по относительным путям, без service worker, без alert/confirm/prompt, без window.print, без download-ссылок).
- Прогресс в localStorage (все обращения в try/catch, фолбэк в память) + экспорт/импорт прогресса текстом для переноса между устройствами.
- Mobile-first (390px без горизонтального скролла), светлая и тёмная тема на CSS-токенах (prefers-color-scheme + data-theme), клавиатура, видимый focus, prefers-reduced-motion. Шрифты Google Fonts с кириллицей. Визуальный язык — дорожные знаки (синий, красный, жёлтый на «асфальтовых» нейтральных).

МЕТОДИКА (обязательно реализовать все пункты)
1. Активное припоминание: сначала ответ, потом подсказка. После ответа: правильный — зелёным, выбранный неверный — красным, пояснение с выделенным пунктом ПДД и подсвеченными числами с единицами (м, км/ч, мм, мг/л, лет…).
2. Интервальное повторение (Лейтнер, коробки 0–6): 10 мин → 1 д → 3 → 7 → 14 → 30. Новый вопрос, отвеченный верно с первого раза, — сразу в коробку 2. Ошибка — коробка 1. Досрочное повторение интервал не увеличивает. Если задана дата экзамена — интервалы сжимаются до половины оставшихся дней.
3. Отработка ошибок внутри сессии: неверный вопрос возвращается через 3 вопроса, затем через 6, пока не будет 2 верных ответа подряд.
4. Кнопка «Угадал» (клавиша G) — случайный верный ответ пересчитывается как ошибка.
5. Порции новых вопросов (по умолчанию 20), упорядоченные по темам от основ к сложному: Общие положения → Знаки → Разметка → Светофор/регулировщик → Манёвры → Расположение → Скорость → Обгон → Остановка → Перекрёстки → Переходы → Ж/д → Автомагистрали → … → Медпомощь → Ответственность. Повторения перемешиваются с новыми (2 повтора : 1 новый).
6. Дубли вопросов между билетами учитываются один раз (по id), но в билетах показываются все 20.
7. Озвучка через Web Speech API (ru-RU): кнопка «Озвучить», автоозвучка в настройках, аудиорежим «Слушать» (вопрос → пауза 2,5 с → правильный ответ и пояснение → следующий) для повторения в дороге.
8. Шпаргалка: таблицы скоростей, расстояний (5/15/3/50/100 м), запретов обгона/разворота/заднего хода/остановки, приоритетов на перекрёстке, ж/д переезда, буксировки, световых приборов, аварийной остановки, техсостояния (протектор, люфт), детей, первой помощи (30:2, жгут 1 ч/30 мин), 0,16 мг/л — с мнемониками. Каждый факт сверять с пояснениями базы вопросов; не добавлять то, что база не подтверждает или что могло измениться.
9. Тренажёр знаков: картинка → 4 варианта названия из той же группы.

РЕЖИМЫ
- Главная: «шанс сдать сейчас» (Monte Carlo 700 прогонов по реальным правилам экзамена, вероятность верного ответа по коробке: 0.5/0.72/0.88/0.94/0.97/0.985/0.993), выучено/закреплено/дней подряд, план на сегодня (повторить N, новых M, норма в день до даты экзамена), сетка билетов 1–40 с цветом готовности и точкой результата последнего экзамена, краткая методика.
- Учить сейчас (SRS), Экзамен, Билет (решать с подсказками / экзамен по билету / смотреть с ответами / слушать), Темы, Ошибки, Марафон (все вопросы подряд, место сохраняется), Шпаргалка, Знаки и разметка (справочник с поиском + тренажёр), Настройки.
- Экзамен строго по регламенту ГИБДД: случайный билет, 20 вопросов, 4 тематических блока по 5, 20 минут, ответ нельзя изменить, можно пропускать и возвращаться, ответы не показываются (опция в настройках). 0 ошибок — сдал; >2 ошибок или 2 в одном блоке — не сдал; 1 ошибка в блоке → +5 вопросов того же блока из другого билета и +5 минут; любая ошибка в дополнительных — не сдал; время вышло — не сдал. Итог с разбором ошибок и кнопкой «Работа над ошибками».
- Опция «перемешивать варианты ответов» (по умолчанию выкл. — на экзамене порядок фиксирован).
- Клавиши 1–5, Enter/пробел, G. Deep-link по хэшу: #learn #exam #cheat #signs #topics #mistakes.

КАЧЕСТВО

- Проверка перед сдачей: node --check, прогон Playwright (главная, сессия обучения, экзамен с 1 ошибкой → доп. вопросы → «Сдал», экзамен с >2 ошибками → «Не сдал», знаки, шпаргалка, мобильная ширина 390px без горизонтального скролла, тёмная тема, 0 ошибок в консоли).
```
