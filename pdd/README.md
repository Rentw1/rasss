# Тренажёр билетов ПДД

Статический сайт для подготовки к теории в ГИБДД: 40 билетов × 20 вопросов (ABM и CD, по 800 вопросов), все картинки, знаки, разметка. Без сервера и сборки — только HTML/CSS/JS.

## Запуск

```bash
cd pdd && python3 -m http.server 8000   # http://localhost:8000
```

### На свой сервер (VPS) одной командой

```bash
git clone -b claude/pdd-exam-learning-oel8ty --depth 1 https://github.com/Rentw1/rasss.git /tmp/rasss \
  && sudo bash /tmp/rasss/pdd/deploy/install.sh        # или: ... install.sh 9123 — свой порт
```

Скрипт сам найдёт свободный порт (8080, 8081, 8088 …), поставит python3 при необходимости, создаст systemd-сервис `pdd-trainer` с автозапуском, откроет порт в ufw/firewalld и напечатает ссылку `http://IP:порт/`. Повторный запуск обновляет сайт на том же порту.

Хостинг: любой статический (GitHub Pages — workflow `.github/workflows/pdd-pages.yml`, Netlify, nginx). Включить Pages: Settings → Pages → Source: GitHub Actions.

## Методика (что внутри)

| Принцип | Реализация |
|---|---|
| Активное припоминание (testing effect) | Ответ до подсказки, пояснение после |
| Интервальное повторение | Лейтнер: 10 мин → 1 → 3 → 7 → 14 → 30 дней; интервалы сжимаются под дату экзамена |
| Мгновенная обратная связь | Правильный ответ + пояснение с пунктом ПДД; цифры подсвечены |
| Отработка ошибок | Ошибка возвращается через 3 и 6 вопросов, пока не будет 2 верных подряд |
| Честная самооценка | Кнопка «Угадал» (G) — случайный верный ответ не засчитывается |
| Блочное изучение | Новые вопросы по темам: знаки → разметка → манёвры → перекрёстки … |
| Мультимодальность | Озвучка (Web Speech), аудиорежим «Слушать», картинки |
| Симуляция экзамена | 20 вопросов / 20 мин / 4 блока; 1 ошибка → +5 вопросов и +5 мин; 2 в одном блоке или >2 — незачёт |
| Метрика готовности | Monte Carlo по реальным правилам экзамена → «шанс сдать сейчас» |
| Опоры для памяти | Шпаргалка цифр и запретов с мнемониками, тренажёр знаков |

## Режимы

Учить сейчас (режим «с нуля»: сначала ответ, потом вопрос) · Блиц 90 с · Достижения и ранги · Экзамен · Билеты 1–40 (решать / смотреть с ответами / слушать) · Темы · Ошибки · Марафон · Шпаргалка · Знаки и разметка (справочник + тренажёр) · Настройки (дата экзамена, порция, перемешивание ответов, озвучка, тема, перенос прогресса).

Клавиши: `1–5` ответ, `Enter` дальше, `G` угадал. Ссылки: `#learn`, `#exam`, `#cheat`, `#signs`, `#topics`, `#mistakes`.

## Мотивация

XP за ответы (бонус за комбо), 10 рангов от «Пешехода» до «Экзаменатора ГИБДД», 20 достижений, цель дня с кольцом прогресса, серия дней, карта активности за 16 недель, блиц с рекордом, звуки и конфетти (отключаются; учитывается prefers-reduced-motion).
